### Repositories

- **[BmnRoot](https://git.jinr.ru/nica/bmnroot)** — the reconstruction and simulation framework
  of the BM@N experiment, which I maintain as part of the team. C++17, ROOT, FairRoot.

- **[align_new](https://git.jinr.ru/nica/bmnroot/-/tree/new_alignment/align_new)** — my own part
  of it: track-based alignment of detector geometry.

- **[klines-toolkit](https://github.com/igor-polev/klines-toolkit)** — continuous collection and
  analysis of Binance futures market data. Python, asyncio, SQLite, plotly, runs as a systemd service.

- **[btc-address-generator](https://github.com/igor-polev/btc-address-generator)** — every Bitcoin
  address format derived from one secret, with the Bech32 path written by hand rather than taken
  from a library. C++17, libbitcoin-system, secp256k1, Qt6.

- **[screen-vision-automation](https://github.com/igor-polev/screen-vision-automation)** — desktop
  automation driven by real-time screen capture and pattern matching. C++17, CMake, vcpkg.

- **[cli-benchmark](https://github.com/igor-polev/cli-benchmark)** — timing statistics for
  command-line programs, sequential or parallel runs, standard library only.
